# Идея проекта

## «Отклик»

«Отклик» — безопасная платформа для обращений школьников, родителей и педагогов за помощью.

Пользователь может спокойно описать ситуацию, получить секретный код обращения и продолжить диалог без регистрации и публикации личных данных. Оператор распределяет обращение, а специалист помогает в отдельном рабочем интерфейсе. При необходимости обращение можно вернуть оператору и передать другому специалисту.

## Зачем это нужно

В чувствительных ситуациях человеку важно получить помощь без лишних барьеров, публичности и необходимости сразу раскрывать контакты. Платформа объединяет простой вход, бережный интерфейс и ролевое разграничение доступа.

## Основные принципы

- минимум собираемых данных;
- доступ к обращению только у тех сотрудников, которым он необходим;
- секретный код вместо обязательной регистрации заявителя;
- понятные статусы и возможность продолжить обращение позже;
- русский mobile-first интерфейс;
- кризисные сигналы и вложения обрабатываются с отдельными ограничениями безопасности.
