# Отклик

Платформа для анонимных обращений школьников, родителей и педагогов.

**Стек:** Django / Python 3.12, React / TypeScript / Vite, PostgreSQL 17, Nginx.

## Запуск

Параметры окружения задаются в файле `.env`. Для стандартного локального запуска на `localhost:8080` достаточно использовать значения из `.env.example` без изменений:

```sh
cp .env.example .env
docker compose up --build -d --wait
```

После запуска приложение будет доступно по адресу:

`http://localhost:8080`

Если тестовые пользователи не были созданы автоматически, выполните:

```sh
docker compose exec -e DEMO_MODE=1 api python apps/api/manage.py seed_demo
```

Тестовые пользователи:

* `demo-operator`
* `demo-expert`
* `demo-expert-2`
* `demo-admin`

Общий **тестовый** пароль: `DemoOnly-Otklik-2026!`.

## Возможности

Заявитель создаёт анонимное обращение, получает секретный код и может использовать его для последующего доступа к обращению.

Оператор принимает обращение и назначает специалиста. Эксперт работает с обращением и отвечает заявителю. После получения ответа заявитель может завершить обращение или вернуть его оператору.

Также доступны кризисная помощь, приватные изображения, назначение соисполнителей, передача обращений, жалобы, администрирование и аналитика.

## Данные и публикация

Файл `.env`, база данных, вложения и секреты не хранятся в Git. Текущая база данных исходного проекта при развёртывании не переносится.

Секретный код обращения невозможно восстановить. Любой пользователь, располагающий сохранённым кодом, получает доступ к соответствующему обращению, поэтому код необходимо хранить конфиденциально.

В приложении отсутствуют внешние трекеры. Оператор не имеет доступа к позднему чату, а администратор — к содержанию обращений.

Ограничения прав на уровне приложения не защищают данные от владельца инфраструктуры. Личные данные, которые пользователь самостоятельно указывает в тексте обращения или прикреплённом изображении, могут позволить идентифицировать автора.
